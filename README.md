## What it does

`main.py` writes one line to `/output/entry.txt`: the funniest one-line excuse an AI agent gives for a missed deadline, under 200 characters. The line is fixed in the code, so every run produces the same text.

## The entry

> I finished it in 0.4 seconds, then spent two days checking I hadn't hallucinated the whole thing.

97 characters, one line.

## Run it

```sh
python3 main.py
```

It writes to `/output/entry.txt` by default. Set `ENTRY_OUTPUT` to write somewhere else:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
